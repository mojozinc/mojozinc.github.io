next query prediction engine

Conversational Search • TiVo Hackathon
Domain: Conversational Search & Intent Prediction
Stack: Python, Graph Algorithms, NLP, Probabilistic Modeling
Award: TiVo Hackathon Finalist

The Next Query Prediction Engine was developed during a TiVo Hackathon to accelerate conversational discovery in entertainment search systems.

The Challenge

Voice and conversational search queries in media apps often suffer from conversational ambiguity. When a user asks: "Find movies with Tom Cruise", their subsequent query might be a refinement ("Only action from the 90s"), an entity hop ("Who directed the second one?"), or a playback command ("Play trailer").

Standard search systems evaluate queries in isolation, missing contextual transitions that are highly predictable when framed across historical session logs.

Probabilistic Graph Modeling

Rather than treating conversation as stateless search events, we modeled multi-turn search trajectories as probabilistic directed graph traversals:

  • Nodes: Semantic intent states (e.g., [Entity: Actor], [Filter: Genre], [Action: Stream]).
  • Edges: Transition probabilities learned over aggregated session interaction graphs, weighted by user cohort and temporal decay.
  • Predictive Prefetching: Allowed the search backend to pre-warm candidate entity result sets before the user finished speaking or typing their follow-up prompt.

Key Takeaways

The system demonstrated that graph-structured intent modeling dramatically reduced perceived search latency while increasing conversational completion rates, paving the way for proactive conversational suggestion chips in smart TV interfaces.
