🎛️ agent-deck

Active Development • Work in Progress WIP
Status: Active Development (v0.3)
Stack: Rust, egui / eframe, tokio, WSL2, tmux
Source: github.com/mojozinc/agent-deck ↗

agent-deck is a retro Winamp-inspired floating desktop activity deck and multi-stream session monitor designed for AI coding assistants (Gemini / Antigravity, Claude Code) running natively on Windows and inside WSL2 (with native tmux session inspection).

The Motivation

As agentic coding tools have shifted from single chat prompts to asynchronous multi-agent orchestration, developers frequently run multiple background sessions across local terminals, WSL2 containers, and tmux panes.

Without a persistent HUD, it is easy to lose track of which agent is reasoning, which one is waiting on user input or confirmation, and which completed its execution. agent-deck brings back the tactile, compact elegance of late-90s floating media players to solve modern AI developer workflow visibility.

Key Features

  • Dynamic Environment Discovery & Zero-Session Filtering: Auto-detects connected hosts (Windows, WSL2 distros like clibox or ubuntu). Environments with 0 active sessions automatically hide to minimize visual noise.
  • Tactile Status LEDs & VU Equalizer: Visualizes agent states (emerald for reasoning, solid green for tool runs, amber for input required, cyan for done) with dancing 6-segment LED VU equalizers.
  • Native tmux Inspection: Automatically extracts pane titles and coordinates from tmux list-panes inside WSL2.
  • Smart Ticker Display: Smooth horizontal marquee that displays real-time tool arguments and streaming outputs, pausing instantly when human confirmation is needed.
  • Session Semantic Renaming: Resolves smart titles using markdown headings and workspace basenames, with in-place [EDIT] controls persisted across restarts.
  • Floating Window Chassis: Always-on-top, frameless draggable window with interactive font zoom (A+/A-) and responsive vertical resizing.

Architecture

Organized as a modular Rust Cargo workspace: 

agent-deck/
├── Cargo.toml               # Workspace Coordinator
├── Makefile                 # Unified Workspace Dev Commands
├── Launch.bat               # Windows Launcher
└── crates/
    ├── agent-deck-core/     # Shared protocol (AgentState, SessionEvent)
    ├── agent-deck-ui/       # Windows GUI (Rust + eframe/egui)
    └── agent-deck-daemon/   # WSL2 Linux Bridge Daemon (tokio + tmux inspector)

Development & Local Build

The project includes a unified Makefile for rapid local development across host boundaries: 

# Build and launch the Windows desktop widget
make run-win

# Run WSL2 bridge daemon in development mode
make dev-wsl

# Build release binaries across workspace
make build
