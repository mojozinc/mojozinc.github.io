centralized notification platform

Distributed Systems • Sundial Hackathon → Production
Domain: Real-time Collaboration & Event Streaming
Stack: TypeScript, Novu, Redis Queues, PostgreSQL, WebSockets
Origin: Sundial Hackathon Champion → Core Production Service

The Centralized Notification Platform is a unified event delivery and collaboration infrastructure built to power real-time comments, analytical dashboard sharing, metric alerts, and user mentions across the Sundial analytics platform.

From Hackathon to Production

As collaborative analytics grew in Sundial, multiple product subsystems independently implemented fragmented notification logic—leading to duplicate emails, desynchronized unread badge counts, and edge cases around workspace access controls.

During a 48-hour hackathon, we designed an event-driven architecture utilizing Novu as the multi-channel delivery core (in-app feed, email digests, and Slack integrations), paired with a centralized permission evaluation engine. Following its hackathon victory, we hardened and scaled the system into Sundial's tier-1 notification backbone.

Core Architecture

  • Permission-Aware Dispatch: Every notification payload evaluates real-time workspace access policies, ensuring that users only receive alert updates or mention previews for dashboards and time-series cuts they are authorized to view.
  • Debounced Digest Queues: High-frequency analytical threshold alerts and threaded comment discussions are automatically coalesced and debounced via Redis queues, preventing alert fatigue.
  • Multi-Channel Routing: Dynamically routes events between in-app WebSocket banners, Slack webhooks, and asynchronous email digests based on explicit user notification preferences and online presence.
